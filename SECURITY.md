# Security policy

null_gate is designed to run on a trusted home network with no login. Please read the [Security section of the README](README.md#security) for what it does and does not protect against.

## Reporting a vulnerability

Please **do not open a public issue** for security problems. Use GitHub's private reporting instead: the repository's **Security** tab → **Report a vulnerability**.

Include the version (Settings → Updates), how to reproduce it and what an attacker could do. You will get a reply as soon as possible, and fixes ship as a normal release that installs automatically.

## Supported versions

Only the latest release is supported. Automatic updates keep installs current.
